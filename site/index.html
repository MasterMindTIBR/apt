Repositório APT da MasterMind TI

Pacotes para Proxmox VE 9 e Debian 13 (trixie): mm-pve-tools, mm-gw-restore, o File Restore com ntfs-3g e plugin de dedup, e a configuração deste repositório.

  • URL: https://apt.mastermindti.cloud/debian, distribuição trixie
  • Componentes: stable (releases promovidas) e testing (pre-releases, para lab)
  • Chave: mastermind-archive.gpg, impressão digital @FINGERPRINT@

Cluster Proxmox VE: bootstrap

Como root, em qualquer node do cluster. O script instala o mastermind-apt-config (conferido pelo SHA256 da release), ajusta o canal e instala o mm-pve-tools em todos os nodes online.

curl -fsSLO https://apt.mastermindti.cloud/bootstrap-cluster.sh
less bootstrap-cluster.sh                 # revise antes de rodar
bash bootstrap-cluster.sh --check         # só leitura
bash bootstrap-cluster.sh --dry-run       # mostra o plano
bash bootstrap-cluster.sh                 # canal stable
bash bootstrap-cluster.sh --channel testing   # lab

Gateway de restore (VM Debian 13), a partir de um node:

bash bootstrap-cluster.sh --gateway <ip-ou-nome-do-gateway>

Depois do bootstrap, as atualizações vêm com apt full-upgrade.

Instalação manual (um host)

curl -fsSL https://apt.mastermindti.cloud/mastermind-archive.gpg \
  -o /usr/share/keyrings/mastermind-archive.gpg
# confira a impressão digital acima:
gpg --show-keys /usr/share/keyrings/mastermind-archive.gpg

cat > /etc/apt/sources.list.d/mastermind.sources <<'EOF'
Types: deb
URIs: https://apt.mastermindti.cloud/debian
Suites: trixie
Components: stable
Signed-By: /usr/share/keyrings/mastermind-archive.gpg
EOF

apt update
apt install mastermind-apt-config     # assume a chave, o .sources e o pin
apt install mm-pve-tools              # node do PVE (traz o ntfs3g)

O mastermind-apt-config instala o pin que faz o apt preferir os builds da MasterMind:

Package: proxmox-backup-file-restore proxmox-backup-restore-image
Pin: release o=MasterMind
Pin-Priority: 990

Canal

mastermind-apt-channel            # mostra o canal atual
mastermind-apt-channel testing    # stable + pre-releases (lab)
mastermind-apt-channel stable     # só releases promovidas
apt update

Voltar aos pacotes oficiais da Proxmox

apt purge mm-pve-tools pve-file-restore-ntfs3g
apt purge mastermind-apt-config       # remove .sources, chave e pin
apt update
apt install --allow-downgrades \
  proxmox-backup-file-restore=<versão-oficial> \
  proxmox-backup-restore-image=<versão-oficial>

Use apt-cache policy proxmox-backup-file-restore para ver as versões oficiais disponíveis.
